Upstream watch#

A second weekly job reads WATCHLIST.toml — CMR collections, STAC collections, Earth Engine assets, static files, station counts, PyPI releases, and a dozen provider changelogs — diffs each against the snapshot in data_status/watch/, and opens one digest issue labelled upstream-watch with a section per category. Its to-dos (action needed, worth adding) are checkboxes: when the next digest opens it closes the previous one and carries every unticked to-do forward, so nothing is dropped by closing. If nothing changed, no issue is opened.

pixi run -e dev watch   # fetch and diff, writing nothing

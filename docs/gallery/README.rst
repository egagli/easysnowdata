Example gallery
===============

One short script per product: load it over one area of interest and draw one
figure. Every script here is executed when the docs are built, so a figure on
this page is a figure the package produced against live data on that day.

Examples marked *this example was not executed* need provider credentials and
run only in the scheduled build; everything else runs on every pull request.

Each page offers the script and a Jupyter notebook to download.
